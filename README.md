# SPS
Streaming Platform Service : une plateforme vidéo façon YouTube, construite pas à pas pour
apprendre le développement backend et frontend.

- **Le parcours** : [PLAN.md](PLAN.md), découpé en mini-projets, de « Hello » à une plateforme
  complète (comptes, envoi et transcodage des vidéos, lecture HLS, commentaires, abonnements...).
- **L'accompagnement** : [CLAUDE.md](CLAUDE.md) explique comment Claude aide sur ce dépôt :
  des questions, des indices et des ressources, pas de solutions toutes faites.
- **Une version complète** existe sur la branche [`reference`](https://github.com/GauthierDefrance/SPS/tree/reference) :
  un exemple de point d'arrivée, à consulter seulement si on le choisit.

**Pile visée :** Java 21 · Spring Boot · PostgreSQL · SeaweedFS (S3) · RabbitMQ · FFmpeg ·
Vue 3 + Vuetify + Font Awesome · Docker Compose
